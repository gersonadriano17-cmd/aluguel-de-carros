Sobre o projeto

O FP Sellection é uma página web de aluguel de carros com uma
interface moderna e interativa. O projeto apresenta veículos para
aluguel e possui uma tela de login antes do acesso à página principal.

A identidade visual utiliza principalmente tons de roxo, preto e
verde-limão, com foco em carros esportivos.

Página de aluguel de carros

Na página principal, o usuário pode:

Visualizar os carros disponíveis;

Navegar entre os veículos;

Ver o carro em destaque;

Acessar o botão Saiba Mais;

Curtir carros;

Salvar carros de interesse;

Navegar pelas áreas Home, Carros e Fale Conosco.

Sistema de login

O projeto possui uma tela de login com:

E-mail;

Senha;

Visualização/ocultação da senha;

Opção Lembrar de mim;

Esqueci minha senha;

Botão ENTRAR;

Opção Criar conta.

Ao clicar em ENTRAR, o usuário é direcionado para a página principal
(index.html).

Interação com os carros

Sistema de curtidas

Cada carro possui uma opção de curtida. O usuário pode curtir um veículo
e visualizar a quantidade de curtidas associada a ele.

Esse recurso aumenta a interatividade da página e permite demonstrar
interesse pelos carros.

Sistema de salvamento

O site também possui um sistema de salvamento de carros. O usuário pode
marcar veículos para encontrá-los novamente e manter uma seleção dos
carros que deseja analisar.

Identidade visual

O projeto utiliza:

Degradês em roxo;

Elementos escuros;

Destaques em verde-limão;

Tipografia moderna;

Imagens dos veículos em destaque;

Botões arredondados;

Transições e efeitos visuais.

Como executar

Abra a pasta do projeto no Visual Studio Code.

Confira se os arquivos estão nas pastas corretas.

Mantenha a pasta image junto dos arquivos do projeto.

Abra login.html.

Execute com o Live Server.

Faça o login.

Depois de entrar, o usuário será direcionado para index.html.

Objetivo

O objetivo do FP Sellection é criar uma experiência de aluguel de
carros moderna, organizada e interativa, reunindo uma tela de login, uma
vitrine de veículos e recursos de curtidas e salvamento.
